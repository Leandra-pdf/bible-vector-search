# Bible Vector Search

A TypeScript proof of concept (POC) for chunking the King James Version (KJV) of the Bible, generating vector embeddings, storing them in ChromaDB, and enabling semantic search.

## Overview

This project explores how to prepare a text corpus for semantic search using vector embeddings and a vector database.

The project uses the King James Version of the Bible from Project Gutenberg as its source text. The goal is to develop a parsing and chunking strategy, convert the resulting text chunks into embeddings, and store them in ChromaDB so relevant passages can be retrieved through semantic search.

## Tech Stack

- **TypeScript** — application logic
- **OpenAI API** — text embeddings
- **ChromaDB** — vector storage and retrieval
- **Node.js and npm** — runtime and package management

## Data Source

The Bible text is the *King James Version of the Bible*, downloaded from Project Gutenberg.

- Source: https://www.gutenberg.org/ebooks/10
- Local file: `data/bible/kjv.txt`

The source file includes Project Gutenberg's introductory material, book headings, and Bible text. The implementation will handle the source format when parsing the text.

## Setup

### 1. Install dependencies

Clone the repository and install its dependencies:

```bash
npm install
```

### 2. Configure environment variables

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_api_key_here
```

Replace the placeholder with your OpenAI API key. Do not commit your `.env` file or expose your API key.

### 3. Start ChromaDB

Start the local ChromaDB server:

```bash
npm run chroma
```

Keep the server running while using the application.

- `.env` contains local credentials and must not be committed.
- `node_modules/` contains installed dependencies and must not be committed.

- `/data/security/` contains local security test fixtures and is excluded from this project's Git repository.
